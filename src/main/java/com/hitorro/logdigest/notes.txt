ProvisionChild uri=/breadcrumb/provisionChild
======

example: origin-services.HiTorro.net/breadcrumb/provisionChild?parent=bc9d1e39c494440e8d963774c3bee8fc

Uses Last Part of path: Yes
Has Parameters: parent

Notes: part of /breadcrumb/<action>


Playlist uri=/breadcrumb/playlist
======

example: origin-services.HiTorro.net/breadcrumb/playlist/925ba603a5804f7b98562231b629a2b5/PID_011808

Uses Part of path: Yes but not last part
Has Parameters: yes as part of path

Notes: part of /breadcrumb/<action>



- Hostingsite uri=/ping/hostingsite
======

example: origin-services.HiTorro.net/ping/hostingsite?breadcrumb=925ba603a5804f7b98562231b629a2b5&hosturl=http%3A%2F%2Fwww%2Ejaiku%2Ecom%2Fblog%2F


Uses Last Part of path: Yes, last part, OR part of /ping/<action>

Has Parameters: breadcrumb

Notes: Have no idea what its used for



- UserAction X  uri=/ping/useraction
======

example: origin-services.HiTorro.net/ping/useraction?action=play&breadcrumb=f007c9881bed4c4dbc9983fd37815b03&mediaId=PID_013171&time=0

Uses Last Part of path: /ping/useraction

Has Parameters: action, breadcrumb, mediaid, time




- Beacon (uri=*/HiTorro_beacon.gif)
======

example: origin-www.HiTorro.net/home/technology/2149/%5C%22http:/media1.HiTorro.net/graphics/HiTorro_beacon.gif?p=/home/technology/2149/netgear-introduces-gigabit-speed-to-their-stackable-smart-switches%5C%22

Uses Last Part of path: No


- Resource
======  uri/*.[resource extension] or some other extensions.

example: origin-iphone.HiTorro.net/techone/iui/options-extend.png

Uses Last Part of path: yes anything that ends with an image, swf txt, ico, some other extension

Notes: Just chuck it
